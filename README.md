# MixPilot

Загрузил музыку → выбрал, что хочется получить → нажал одну кнопку → получил три готовых варианта.

Windows-приложение: ремиксы в пяти стилях, соединение песен и каверы собственным голосом. Разбираться в темпе, тональности, дорожках и эквалайзере не нужно — пожелания пишутся обычными словами. **Всё аудио обрабатывается на вашем компьютере** и никуда не отправляется; в облако уходит только текст ваших пожеланий, и то по тумблеру.

## Установка

Скачайте `MixPilot-<версия>-setup.exe` из [релизов](https://github.com/artemkrotkov1612-crypto/mixpilot/releases) и запустите. Ставить Python, FFmpeg или CUDA не нужно — приложение доустановит всё само при первом запуске.

Что понадобится: Windows 10/11 (64 бита), видеокарта NVIDIA, около 8 ГБ на диске и интернет для первого запуска (загрузка компонентов занимает несколько минут и делается один раз).

Если движок не собрался, повторить установку компонентов можно без окна:

```cmd
MixPilot.exe --setup
```

## Что умеет

- **Ремикс** — Slowed, Bass Boosted, Phonk, Club, House. Три варианта за один раз, дальше можно править: «медленнее», «мощнее припев» или своими словами.
- **Соединить песни** — mashup из нескольких треков: плавно, по-клубному, «вокал одного поверх музыки другого» и не только.
- **Мой голос** — записали несколько фраз, и любую песню можно спеть своим голосом. Без обучения модели: голос работает сразу после мастера записи.
- **Оформление** — название и обложка для готового трека, передача на телефон по QR-коду в домашней сети.

## Архитектура

- `electron/` — main-процесс: окно, жизненный цикл Python-worker (`workerManager.cjs`), preload-мост.
- `src/` — React + TypeScript (Vite), дизайн-система «Aurora Noir» (`src/app/theme.css`).
- `worker/` — Python 3.11 + FastAPI на `127.0.0.1:<свободный порт>`; управляется через uv.
- `scripts/` — dev-обвязка под портативные Node/uv воркспейса `C:\TheIceBoys\TOOLS`.

## Запуск (dev)

```cmd
scripts\dev.cmd
```

Поднимает vite (порт 3520), Electron и Python-worker (первый запуск сам создаст `.venv` по `uv.lock`).

## Сторонние компоненты

FFmpeg входит в дистрибутив отдельной программой (код не встраивается) и распространяется на условиях GPL v3 — уведомление и ссылки на исходные тексты лежат в `build\FFMPEG-LICENSE.txt`.

## Правила

- Никаких музыкальных терминов в обязательном UI-пути; названия моделей пользователю не показываются.
- Аудио и голос не покидают компьютер; в облако (Claude API) уходит только текст — по тумблеру.
- `.cmd`/`.ps1` — только ASCII (ловушки кодировок Windows PowerShell 5.1).
